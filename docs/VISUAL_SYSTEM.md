# 观澜视觉与动效规范

三套主题共用布局和控件结构，分别使用潮线、山势、星轨作为工作台边缘装饰。装饰不进入预览画面或文字编辑区；主题切换同时更新悬停、按下、选中和禁用色阶。

| 主题 | 背景 | 面板 | 强调 | 适用场景 |
|---|---|---|---|---|
| 潮汐 | `#111B24` | `#1B2934` | `#8BBFD0` | 默认逐镜工作 |
| 墨山 | `#151C1A` | `#202A25` | `#A6C9AF` | 长时间文字创作 |
| 星垣 | `#181923` | `#252633` | `#C2B6E0` | 分镜展示与个人偏好 |

基础间距为 8px，紧邻元素可用 4px；面板标题栏 32px、内边距 12px。正文建议 13px/20px，辅助文字 12px/18px。线性图标统一 20px、1.5px 描边；可点击热区至少 40×40px。基础控件与工作区面板圆角 4px，设置卡与弹层 6px，媒体卡 8px。强调色只用于主操作、选中和焦点。

## 工作区统一校准

- **导航**：全局入口用同一套 SVG 线性图标，18px/1.7px 描边；折叠侧栏使用 20px 图标、至少 44px 高热区。选中项同时用背景色和左侧 2px 强调线表示，避免只靠颜色辨别。首页、项目库与统一资产库不再重复显示项目场景目录；镜头工作区保留与当前项目有关的场景上下文。
- **层级**：工作区以背景、面板、输入面三层区分。面板统一使用 1px 低对比边框和顶部极浅内高光；标题栏统一至少 36px。顶部任务、消息等入口使用同一尺寸和状态，悬浮面板保留 8px 圆角及深色阴影。三套主题仅替换色值，不改变信息结构。
- **控件**：输入框、下拉框、文本区统一 5px 圆角；悬停提高边框对比，键盘焦点使用 2px 实线外框和 3px 柔和扩散。禁用控件保持可读，不能仅靠透明度传递含义。辅助按钮至少 36px 高；主导航及常用操作至少 40px 高。
- **排版**：面板标题 13px/600，正文 13px/20px，辅助说明 12px/18px；时间、数量等数字采用等宽数字特性。非关键说明使用二级文字色，主操作和当前选择使用主题强调色。长内容在各自面板内滚动，不让整页横向溢出。
- **装饰与助手**：潮线、山势、星轨只用于首页和工作区外围背景；进入非首页编辑区后降低至约 10% 不透明度。澜芯入口统一为 48×48px；右侧检查器和资产详情底部留出至少 72px 安全区。
- **创作优先**：剧本页让完整剧本与故事记忆先于制作说明出现；制作路径置于页末并默认折叠。独立画布的空状态提供直接添加节点的操作，画布平移只响应非交互空白处，不截获按钮点击。
- **键盘与动态**：弹出任务或消息面板后焦点进入面板，关闭后返回原入口；Escape 可关闭。遵循系统“减少动态效果”设置，保留可见的状态变化而不依赖动画传意。

片头提供首次、每次与关闭三档；默认首次。三套片头各有原创概念画面与对应 SVG 动效，普通片头约 3.1 秒，可跳过；主界面已准备好后，片头在 320ms 内渐隐交接。系统偏好减少动态效果时静态显示并在约 150ms 后进入工作台。三张 WebP 合计约 0.52 MB；没有背景视频或无限粒子。交互微动效目标值：快速反馈 120ms、普通状态 180ms、面板展开 220ms；加载状态优先显示真实任务进度，不使用无限闪烁。
