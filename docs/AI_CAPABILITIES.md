# 观澜的 AI 能力边界

观澜不是每个按钮都调用 AI。涉及原文事实、镜头连续性和成片判断的地方，保留本机处理与人工复核，避免把模型推测当作成片事实。

| 区域 | 已有 AI 能力 | 不调用模型也能做什么 | 使用条件与边界 |
|---|---|---|---|
| 剧本与故事记忆 | 从原文建立故事记忆、编写独立剧本草稿 | 导入、编辑、手动建第一镜 | 需文字模型；草稿采用前不覆盖正式剧本 |
| 视觉资产 | 提取人物、场景和道具设计；生成候选图 | 手动建资产、导入参考图、确认版本；跨项目复用已确认资产 | 文字设计与生图可用不同连接；候选图需人工采用；复用副本必须核对当前项目原文 |
| 规划与镜头 | 自动规划、逐镜方案和局部修改建议 | 手动规划、编辑镜头、检查连续状态 | 需文字模型；生成结果不自动审核通过 |
| 侧栏无限画布 | 独立 Seedance 系列自由视频节点，或将现有镜头提示词作为上游绑定逐镜生成 | 空白画布排布、引用镜头与资产、自由提示词、连线、预览合成提示词、保存节点位置 | 只有显式连接的上游进入目标；自由任务不写入逐镜结果；未确认资产阻断生成；需自有火山方舟密钥与额度 |
| 单镜生视频 | 通过火山方舟 Seedance 系列文字或明确选择首帧图生成候选 | 配置连接、查看历史任务、导入外部视频并人工回看 | 需用户自己的火山方舟密钥和额度；每次提交前明确确认，选择首帧才上传对应参考图；任务完成后视频保存到本机资料目录 |
| 拉片学习 | 一键自动拆镜、逐镜视觉分析并生成待复核报告；也可单独分析已有镜头 | 导入本机视频或公开链接、本机候选切点、手动笔记、导出带图 Excel | 需连接支持图片输入的文字模型；不会读取音轨或完整帧间运动 |
| 短片诊断 | 对五张等距采样帧及人工观察作辅助诊断 | 播放、手写观察与修改计划、导出报告 | 需支持图片输入的文字模型；声音与未采样动作须人工核对 |
| 澜芯和技能 | 已连接模型时开放问答、起草技能文字 | 新建、切换和删除独立对话；按项目阶段提示下一步、显示任务进度、内置指南问答、受控工作台任务、手工建技能与管理文件 | 技能中的代码不会运行；模型只执行允许的动作 |
| 拉片资料库 | 将原片用于新拉片练习后，可在练习里调用视觉分析 | 按期数与资料类型浏览、打开原文件 | 资料索引本身不上传模型，也不自动改写项目 |
| 成片回填、审稿、Token 看板、交付 | 无自动成片判断 | 本机播放、人工反馈、用量统计、版本冻结与导出 | Token 看板只统计观澜自身调用；剪辑在外部完成，服务商视频费用暂不纳入 Token 看板 |

## 单镜生视频的使用范围

先在“镜头工作区 → 成片检查 → 配置 Seedance 连接”填写火山方舟 API 密钥和当前控制台可用的模型 ID。选中镜头后点“用本镜生成视频”，检查自动带入的逐镜提示词、时长、画幅和分辨率，再确认提交。观澜只提交这一次任务，不自动批量计费或失败后重试。结果可在该镜头查询，完成后下载到当前资料目录；点“加入本镜成片检查”才会进入播放、对照和人工反馈环节。提交后重开观澜仍能继续查询已取得任务号的任务。网络中断导致提交结果不确定时，应先到火山方舟控制台核对，避免重复付费。

首帧参考图默认不选；选中已确认资产的参考图时，确认提交后才发送该图。观澜仅存任务模式与参考图名称，不把图片数据写进生视频任务记录。目标视频模型列表还包含 Vidu、PixVerse、Pika、海螺及开源模型等交付预设；这些预设不能在观澜内直接提交，未知时长不会被当作已核实规格。模型凭据由本机系统加密保管，不随项目备份。下载结果归用户资料目录；迁移资料目录时一起迁移。

## 用链接开始拉片

进入「拉片学习 → 我的拉片练习」，点「粘贴视频链接」。支持公开 HTTPS 视频直链（MP4、WebM、MOV 等）；粘贴包含链接的分享文字也会提取其中的地址。便携版已随包附带 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 与 FFmpeg 解析组件，换电脑不需要另装这两项；不同站点的可用性仍随站点规则变化。需要登录、受保护或无法公开获取的视频，请先通过你可用的方式保存为本机视频，再使用「导入本机视频」。

链接导入最多 512MB，只导入单个视频。导入后先检查播放器能否解码、时长是否正确，再点「一键 AI 拉片」：本机按自适应采样间隔（至少 0.5 秒、全片约 600 个采样点以内）寻找相对邻近画面的变化峰值，并把切点依据和低可信度位置显示在工作区。这个思路参考了 [PySceneDetect 的自适应切镜设计](https://www.scenedetect.com/docs/latest/api/detectors.html#scenedetect.detectors.adaptive_detector.AdaptiveDetector)，实现为观澜自有代码；它不是逐帧精确剪辑，短于采样间隔的镜头、溶解和大幅运动仍要人工回看。随后按每批最多 6 镜向已连接的视觉文字模型发送每镜两张采样图，生成逐镜分析与图文报告。开始前会显示计费及覆盖旧笔记提示；停止或模型失败时已完成批次保留，可点「继续分析剩余镜头」只补做未完成部分。报告不会自动标记为已复核，也不会自动存入导演参考库。AI 分析前需配置支持图片输入的文字模型与自己的 API 凭据，联网调用可能产生费用。来源链接会保存在本机拉片记录中，供复制核对。
